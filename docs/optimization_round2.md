# 性能优化第二轮（2026-11-10，真实视频回归之后）

第一轮见 `docs/optimization.md`。本轮在真实视频（5,625 帧回归素材）上先做
阶段剖析，再动手：全帧检测中位 2.75 ms（本机、帧预载）中，掩膜管线
（二值化 0.64 + 形态学开 0.48 + 闭×2 0.51 + 轮廓 0.25）占 68%，角点精修
（含整帧灰度转换 0.25）约 0.30 ms，位姿/跟踪已不是瓶颈（0.07 / 0.11 ms 级）。

## 1. 形态学链精确合并（已采纳）

原链：`OPEN(3×3)` 后 `CLOSE(3×3, iterations=2)`，共 6 次全图形态学。
平坦 3×3 矩形结构元下，迭代膨胀/腐蚀可复合（dilate3∘dilate3 = dilate5），
整链等价于 **erode3 → dilate7 → erode5**（3 次）。

等价性证据：独立对照程序在随机掩膜（多密度多尺寸）、结构化掩膜（含贴边
图形）与 300 帧真实掩膜上共 470,329,947 像素逐像素比对，差异为 0。
（注：第一轮否决的 CLOSE 2→1 是改变运算本身；本项是代数等价变形，不同。）

## 2. 角点精修改为逐灯条灰度小图（已采纳）

原实现：finishDetect 对整帧做一次 BGR→灰度（1440×1080），refineCorners
只读其中每条灯条附近的小块。改为：质心阶段只转换灯条外框小图；边缘搜索
阶段按采样点的可达范围（质心 ± 轴向 0.7L ± 法向 half + 1.5 px）再取一块
小图采样。cvtColor 逐像素确定性、小图采样域经证明覆盖全部采样点、图外
采样返回 0 的语义与原实现一致，因此结果逐值相同。

## 3. ROI 策略 A/B（真实视频，结论：维持现状）

在真实视频上对窗口策略做三方对照（窗口 = 上一帧装甲外框 +110 px，
全帧结果为参照）：

| 策略 | 3.avi 漏检 | 4.avi 漏检 | 策略均耗时（3/4.avi） |
|---|---|---|---|
| 现状：每 30 帧全帧 + 空结果重试 | 58 | 19 | 1.24 / 1.10 ms |
| + 数量下降即同帧全帧重扫 | 39（−33%） | 12（−37%） | 1.75 / 2.10 ms |
| 全帧周期 30→15 | 55 | 19 | 1.48 / 1.27 ms |

下降触发能找回约 1/3 漏检，但 4.avi 上 515 次触发只找回 7 块（高速旋转
时装甲正常旋出画面也会触发），成本 +0.5~1.0 ms/帧；缩短周期基本无效
（漏检主要是同帧新旧板交替，不是扫描间隔问题）。**结论：出厂策略不变**，
`--roi` 维持默认关闭；若日后对丢板恢复更敏感，下降触发是现成的杠杆。
更根本的解法是窗口包含跟踪器预测的同车其他装甲位置（旋入的板由整车
状态预测，而非等它被看见），列为后续项，需带跟踪器的端到端验证再落地。
