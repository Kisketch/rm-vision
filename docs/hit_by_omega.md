# 命中率随目标角速度的变化（E-01）

每发按射击时刻估计的 `|w|` 分桶。板在画面里的横向速度 = ω·r，所以 ω 越大，同样的时间误差造成的角误差越大。

| \|ω\| rad/s | 射击数 | 命中 | 命中率 |
| --- | --- | --- | --- |
| 0-2 | 630 | 458 | 72.7% |
| 2-4 | 543 | 336 | 61.9% |
| 4-6 | 278 | 151 | 54.3% |
| 6-8 | 743 | 454 | 61.1% |
| 8-10 | 1206 | 863 | 71.6% |
| 10-12 | 85 | 52 | 61.2% |
| 12+ | 4 | 0 | 0.0% |

## 结论

- 低速段（<4 rad/s）命中率 67.7%（1173 发），高速段（≥8 rad/s）71.6%（1206 发）。
- 若高速段明显更低，说明限制来自“同样的预测误差在快速旋转下放大”，对应解法是更高帧率/更好的 yaw 观测，而不是调开火窗口。
- 若两段接近，则说明瓶颈在检测与标定（系统性误差），与转速无关。

*ω 来自滤波器状态，非真值；分桶仅用于相对比较。*
