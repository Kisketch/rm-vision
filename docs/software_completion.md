## 性能（本轮实测后优化）

`solve()` 是 aimer 的热点（每帧最多调用 5 次）：真空下落初值使定点迭代
平均 3.0 → 2.5 次，RK4 导数里的 `hypot` 换成 `sqrt(x²+z²)`（数值差
~1 ulp）。本机基准：`solve(5, 0.5)` 109 → 40 µs/次，跟踪+瞄准整帧
283 → 155 µs；解算俯仰与改前黄金值偏差 ≤ 6.4e-5 rad（≈0.004°，在求解器
自身 5e-4 m 收敛判据内，黄金测试容差已相应改为 2e-4 并注明原因）。
检测器在合成 1440×1080 帧上约 5.9 ms/帧，是帧预算的大头，但其流水线
没有等价变换级别的安全优化空间，留待真实视频剖析后再动。
