# ADR-002：整车 EKF（13 状态整车模型）而非逐装甲板点跟踪

- 状态：已接受
- 背景：目标是高速旋转的整车（最高 10.5 rad/s 级），逐板点跟踪在装甲板
  交替可见时反复丢跟/重初始化，且无法利用"四块板同属一台刚体"的几何
  约束。
- 决策：跟踪器维护整车状态（中心位置/速度、yaw、角速度、两半径、高度
  差），观测是所有可见装甲板的位姿；瞄准按整车状态预测子弹到达时刻的
  板位。点 KF 与 direct 保留为评测对照策略，不进生产路径。
- 后果：旋转场景命中率从点 KF 的 29.6%/43.1% 提升到 67.5%/68.6%（真实
  视频，条件口径）；代价是模型对几何参数（半径/高度差）敏感，强横移
  （恒速假设失效）成为已知短板，见模拟器 S8 与路线图 P2-10。
- 备选与否决：逐板点 KF——数据否决（上行数字）；IMM 多模型——实验室
  保留，判据为真实视频不退化，未达前不进出厂配置（P2-10 的 NIS 自适应
  子实验已因真实视频退化被否决，见 docs/nis_adapt_study.md）。
- 证据：README 实测数据节、BASELINE.md、docs/performance_charts.md。
