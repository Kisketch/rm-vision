# 参数交互：q_yaw × 开火窗口（E-02）

两个参数各自单变量扫描都出现过“疑似最优值”，这里做 3×3 网格看它们是否互相影响。

| q_yaw | 窗口 24° | 窗口 30° | 窗口 36° |
| --- | --- | --- | --- |
| 1 | 68.5% / 69.6% | 66.5% / 69.2% | 64.2% / 68.7% |
| 3 | 69.4% / 69.2% | 67.6% / 68.7% | 65.9% / 68.3% |
| 8 | 67.3% / 68.2% | 66.1% / 68.0% | 64.7% / 67.6% |

单元格 = 3.avi 命中率 / 4.avi 命中率；综合分 = 0.5·(两视频命中率均值) + 2·(射频和)。

## 结论

- 空格子里的最优组合是 `q_yaw=3` + `窗口 36°`（综合分 111.7）。
- 固定窗口时最好的 q_yaw = 3；固定 q_yaw 时最好的窗口 = 36°。
- 两者一致 → 没有明显交互，单变量扫描的结论可以照用。
- 无论哪种，最终仍要过真实视频门禁（命中率不降、射频不降）。

*每个格子都是完整评测（含检测缓存）。*
