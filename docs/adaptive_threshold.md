# 自适应通道差阈值（A-06）

## 动机

A-04 测到：把画面压到 0.6 倍亮度后，命中率从 67.6% 塌到 37.5%，"有目标帧占比"从
0.965 掉到 0.422 —— 不是瞄不准，是**灯条根本没检出来**。原因是
`channel_diff_threshold = 70` 是**绝对阈值**，画面整体变暗时 R−B 也同比缩小。

## 方法

新增 `detector.channel_diff_adaptive`（默认 **关**）：

```
thr = clamp(mean(R−B) + k·std(R−B), diff_min, diff_max)
默认 k = 4.5，diff_min = 40，diff_max = 120
```

每帧算一次，代价可忽略（`meanStdDev` 在 1440×1080 上 <0.2 ms）。

## 实测

3.avi 前 360 帧的四类画面 × 两种阈值策略：

| 画面 | 固定 70（默认） | 自适应 | 变化 |
| --- | --- | --- | --- |
| 原始 | **67.6%** | 66.5% | −1.1 pp |
| 亮度 ×0.6 | 37.5% | **59.2%** | **+21.7 pp** |
| 亮度 ×1.4 | **59.5%** | 52.3% | −7.2 pp |
| 噪声 σ=8 | 58.3% | — | 未测（噪声不动亮度） |

## 结论：留作"暗场开关"，不做默认

1. 自适应只在**变暗**时赢，在标称和变亮时都输。原因是这类画面是"大面积黑 + 少量极亮"，
   `mean+4.5σ` 会低估最佳阈值（标称场景算出约 50，而调好的值是 70）。
2. 所以默认保持固定 70，不破坏我们已经调好的基线（`regression.py` 全 PASS、delta +0.0）。
3. 真到暗场（赛场灯光弱、镜头光圈小）再打开：

   ```yaml
   detector:
      channel_diff_adaptive: 1
   ```

   代价是同场景下约 −1 pp，收益是"灯条不会整片消失"。

## 更彻底的做法（未做）

- **按曝光补偿**：从相机读 `ExposureTime`/`Gain`，阈值随之线性缩放，比图像统计更可预测；
- **双阈值**：低阈值检出、高阈值确认，再按面积/长宽比筛选（hysteresis threshold）；
- **Otsu on R−B**：在稀疏亮斑场景会退化成接近 0 的分割点，实测不可用。

这三条只在换成工业相机、能拿到曝光参数后才值得做。
